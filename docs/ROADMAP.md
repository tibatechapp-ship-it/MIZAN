## P2 — التالي (كل بند بحالات قبول مختبَرة قبل النشر)

1. **أتمتة PR الإصلاح** — `mizan repair --forge-pr`: فرع معزول ← دفع ←
   فتح PR عبر API بتوكن يوفره المستخدم صراحة؛ الافتراضي يبقى dry-run
   والقرار للإنسان؛ الشجرة المفحوصة لا تُمس أبداً.
2. **`mizan portfolio <dirs…>`** — تقرير HTML واحد يجمع نتائج full-scan
   لمستودعات متعددة: مؤشرات خطورة، اتجاه بين التشغيلات، أخطر النتائج —
   ملف واحد بلا سيرفر ولا حساب سحابي.
3. **تتبع OSV الأسرع** — جلب دلتا دوري، ذاكرة سلبية أذكى، وتحذير تقادم
   الكاش ظاهر في التقرير.

## P3 — بحثي (بلا جدول زمني)

1. Taint عبر الملفات بحد أقصى (bounded) على أنماط source→sink شائعة
   (SQL / SSRF / مسارات) مع قياس زمن معلن لكل مستودع.
2. Reachability عبر استدعاءات (call-graph ثنائي المستوى) وجدول أسماء
   مستعارة أكبر مبني على بيانات حقيقية موثقة.
3. خرائط امتثال (ISO 27001 / SOC 2 / PCI-DSS) فوق نتائج full-scan —
   طبقة عرض للاستخدام الداخلي، لا ادعاء شهادة.

## ما لن نفعله (صراحة)

- **قاعدة ثغرات ملكية**: لا بيانات نملكها ولا فرق بحث — ادعاؤها كذبة.
- **منصة GRC سحابية كاملة**: خارج هوية ميزان كأداة CLI خفيفة؛ نتكامل
  مع المنصات القائمة عبر SARIF 2.1.0 وJSON بدل منافستها.
