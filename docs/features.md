# MIZAN Security — الميزات والقيمة

أداة أمنية واحدة خفيفة وسريعة تحمي الكود والأسرار والتبعيات وإعدادات CI — بأمر واحد، بلا إعداد معقد، وبلا حساب سحابي.

## ماذا تقدم لعميلها؟

| حاجة العميل | ما تقدمه MIZAN Security |
|---|---|
| «أريد أن أعرف مخاطر مستودعي فوراً» | `mizan full-scan .` — تقرير واحد يجمع تحليل الكود، وأنماط الأسرار، والتبعيات، وإعدادات CI، ومخاطر التغيير |
| «لا أريد تنبيهات تقتل تركيزي» | بوابة العتبات: يفشل البناء على الحرج/العالي فقط؛ وخط الأساس يمتص المعروف ويُنبه على الجديد |
| «لا أملك وقتاً للإعداد» | صفر إعدادات للبدء، صفر حساب سحابي، ووضع offline بذاكرة OSV محلية |
| «أخاف أن تلمس الأداة كودي» | قراءة فقط حرفياً — لا تنفيذ للكود المفحوص؛ وأي إصلاح يمر عبر بوابة متحقق منها على فرع معزول |
| «أريد التكامل مع أدواتي الحالية» | SARIF 2.1.0 جاهز لـ GitHub code scanning، وتقارير JSON/HTML، وأكواد خروج لـ CI، وتعليقات آلية على الـ PR |
| «أريد السرعة» | ماسحات متوازية افتراضياً (`--jobs 4`) — زمن الفحص = أبطأ ماسح، لا مجموعها |
| «أريد مساءلة وتوثيقاً» | سجل Ledger يوثق كل قرار هندسي |

## القدرات

- فحص بنية المستودع وتحليل ثابت مبني على AST.
- بوابة عتبات موحدة بدرجات خطورة معيارية عبر كل الماسحات.
- فحص تفاضلي بخط أساس (بصمات sha256 ثابتة لكل نتيجة).
- فحص شامل متوازٍ: 7 ماسحات قراءة-فقط في تقرير واحد.
- تغذية ثغرات التبعيات من OSV.dev بطلبات مجمعة وذاكرة تخزين ووضع offline.
- بوابة إصلاح آمنة متحقق منها (dry-run افتراضياً) + محرك موافقة PR + سجل Ledger.

## التطور

- **v0.8.x** — بوابة العتبات، الفحص التفاضلي بخط الأساس، الفحص الشامل المتوازي، بوابة أسلس.
- **v0.7.0** — موجة تحصين: بنية CI آمنة للفحص والنشر، بوابة إصلاح معزولة، سياسة إفصاح مسؤول.
- **v0.2.0** — محرك الإصلاح المتحقق، تكامل OSV، مخرجات SARIF، سجل Ledger.

## البدء في دقيقة

```bash
pip install -e .
mizan full-scan .

mizan baseline . --save .mizan/baseline.json
mizan scan . --gate --baseline .mizan/baseline.json
```
